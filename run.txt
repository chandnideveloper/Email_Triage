How to Run

Start the Frontend:

bash
cd frontend
npm run dev

Open http://localhost:5173 in your browser.

Start the Backend API (Optional / when ready):

bash
uvicorn email_triage.api.routes:app --host 127.0.0.1 --port 8085 --reload

Note: Vite is configured to proxy all /api calls directly to http://127.0.0.1:8085, with transparent fallback to the local store if the backend is offline.
